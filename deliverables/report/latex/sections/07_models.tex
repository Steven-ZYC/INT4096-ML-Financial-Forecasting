\section{Model Selection and Baselines}
\label{sec:models}

The five models are a linear baseline (ridge restricted to small penalties), Ridge
searched over a wider penalty range, RBF support vector regression, a random
forest, and histogram gradient boosting. Gradient boosting stops early using a
random 10\% of its training rows, so its iteration setting is an upper limit.
Neural networks stay outside the main comparison because the handout discourages
deep learning; Section~\ref{sec:dl} reports a separate test.

The mandatory baseline is naive persistence, $\hat{C}_{t+1} = C_t$. It is free,
strong for a near-random-walk series, and defines zero skill
\citep{makridakis2018m4,hyndman2021fpp3}.

All models share one code path and the same feature columns, and any scaler is
refitted per fold. Tests check column identity and seed determinism.
