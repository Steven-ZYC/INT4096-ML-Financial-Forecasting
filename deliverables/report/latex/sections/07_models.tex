\section{Model Selection and Baselines}
\label{sec:models}

The five families differ in mechanism rather than to reach a count: a linear
baseline (ridge with a small penalty) as a learned floor, Ridge searched over a wide
penalty range, RBF support vector regression as a kernel method, a random forest as
a bagged ensemble, and histogram gradient boosting as a boosted ensemble. Neural
networks stay out of the main comparison because the handout discourages deep
learning; an experimental test is reported separately (Section~\ref{sec:dl}).

The mandatory baseline is naive persistence, $\hat{C}_{t+1} = C_t$. It is not a straw man: for a near-random-walk series it is strong, free, and
defines the zero of the skill scale \citep{makridakis2018m4,hyndman2021fpp3}.

Every family is built through one shared code path, so each receives identical
feature columns in identical order and any scaler sits inside its pipeline where
it is refitted per fold. Tests assert that column identity and that a fixed seed
is deterministic.
